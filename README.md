# MERIDIAN — Multi-Asset Terminal

Сайт-терминал для трейдеров: котировки, аналитика и новости по крипте, форексу
и товарам (золото, нефть) в едином интерфейсе в стиле профессионального
торгового терминала.

> Учебно-коммерческий проект. Демонстрирует вёрстку сложного дата-интерфейса,
> работу с публичными финансовыми API и serverless-бэкенд для скрытия ключей.

## Возможности

- **Бегущая строка котировок** и индикатор настроения рынка (Market Pulse)
- **Дашборд по 5 активам** — BTC/USD, ETH/USD, XAU/USD (золото), WTI (нефть), USD/RUB:
  вердикт (BUY / SELL / не входить), факторы, разбивка уверенности, точность сигналов
- **График цены** (Chart.js) с переключением между активами
- **Календарь экономических событий** и таблица корреляций
- **Лента новостей** с тегами по активам и силе влияния
- **Личный watchlist** — сохраняется в браузере (localStorage)

## Живые данные

| Источник | Данные | Ключ |
|---|---|---|
| CoinGecko | BTC, ETH | не нужен |
| open.er-api.com | USD/RUB | не нужен |
| Twelve Data (через прокси) | золото, нефть | скрыт на бэкенде |

Ключ Twelve Data **не хранится в клиентском коде** — запросы идут через
serverless-функцию Netlify (`netlify/functions/`), которая прячет ключ и отдаёт
сайту готовый JSON.

## Технологии

- Чистый HTML / CSS / JavaScript, без фреймворков
- Chart.js для графиков
- Netlify Functions (Node.js) — serverless-прокси для котировок и новостей
- Дизайн-система: тёмная палитра, шрифты Space Grotesk / IBM Plex, моноширинные цифры

## Запуск локально

```bash
npm install
npx netlify dev      # поднимает сайт + функции локально
```

Открыть `index.html` можно и напрямую — тогда работают источники без ключа
(крипта, USD/RUB), а золото/нефть показывают демо-данные.

## Деплой

Статика + функции разворачиваются на Netlify. Переменная окружения
`TWELVE_DATA_API_KEY` задаётся в настройках сайта (Site settings → Environment
variables), а не в коде.

## Структура

```
index.html              — весь фронтенд (вёрстка, стили, логика)
avia-3d.html            — 3D-визуализация (three.js)
netlify/functions/
  quotes.js             — прокси котировок (Twelve Data)
  news.js               — агрегатор новостей (RSS → JSON)
vendor/three/           — локальная копия three.js
```
