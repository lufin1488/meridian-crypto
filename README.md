# MERIDIAN — Multi-Asset Terminal

Сайт-терминал для трейдеров: котировки, технический анализ и новости по крипте,
форексу и товарам (золото, нефть) в едином интерфейсе в стиле профессионального
торгового терминала.

> Учебно-коммерческий проект. Демонстрирует вёрстку сложного дата-интерфейса,
> работу с публичными финансовыми API, serverless-бэкенд для скрытия ключей,
> движок технического анализа и Telegram-бота на webhook.

## Возможности

- **Бегущая строка котировок** и индикатор настроения рынка (Market Pulse)
- **Динамический топ-10 криптоактивов** по капитализации (авто-подгрузка из
  CoinGecko, обновление раз в сутки) + золото, нефть, USD/RUB
- **Реальный вердикт-движок**: раз в 6 часов по каждому активу считаются
  технические индикаторы (RSI, EMA50/EMA200, поддержка/сопротивление) на дневных
  свечах и формируется вердикт BUY / SELL / НЕ ВХОДИТЬ с уверенностью, текстовым
  обоснованием и обязательным дисклеймером (не индивидуальная инвестиционная
  рекомендация). Связанные новости показываются рядом как контекст
- **График TradingView** (официальный Advanced Chart widget) с переключением
  активов и таймфреймов 5м / 1ч / 4ч / 1д
- **Календарь экономических событий** и таблица корреляций (демо-макет)
- **Лента новостей** из RSS официальных источников с тегами по активам
- **Личный watchlist** — сохраняется в браузере (localStorage)
- **Telegram-бот «Аналитик крипты»**: приоритетные пуши при вердикте «ВХОДИТЬ»,
  настраиваемые второстепенные уведомления (резкие движения цены, важные новости,
  понижение вердикта)

## Живые данные

| Источник | Данные | Ключ |
|---|---|---|
| CoinGecko | топ-10 крипты, дневные свечи для индикаторов | demo-ключ (рекомендуется) |
| open.er-api.com | USD/RUB | не нужен |
| Twelve Data (через прокси) | золото, нефть + их свечи | скрыт на бэкенде |
| RSS (ЦБ РФ, CoinDesk, EIA, Investing.com) | новости | не нужен |

При недоступности любого источника соответствующий блок показывает демо-значения
с пометкой **DEMO** — сайт не ломается.

## Архитектура

Фронтенд статический (`index.html`), вся серверная логика — на Netlify Functions.
Состояние (список активов, вердикты, подписчики бота) хранится в **Netlify Blobs**.

**On-demand функции** (вызываются из браузера):

| Функция | Назначение |
|---|---|
| `quotes.js` | прокси котировок золота/нефти (Twelve Data) |
| `news.js` | агрегатор RSS → единый JSON |
| `crypto-list.js` | отдаёт топ-10 крипты (ленивая инициализация при первом запросе) |
| `verdicts.js` | отдаёт посчитанные вердикты |
| `telegram-webhook.js` | приём апдейтов Telegram (`/start`, `/stop`, `/settings`) |

**Планировщик** (scheduled functions):

| Функция | Расписание | Назначение |
|---|---|---|
| `crypto-list-refresh.js` | раз в сутки | обновляет топ-10 в Blobs |
| `indicators-refresh.js` | каждые 6 часов | считает индикаторы и вердикты, ставит переходы вердиктов в очередь уведомлений |
| `alerts-check.js` | каждые 20 минут | резкие движения цены >3%/час, важные новости, рассылка в Telegram |

Общая логика вынесена в `netlify/functions/lib/` (реестр активов, формулы
индикаторов, клиент CoinGecko).

## Переменные окружения

Задаются в Netlify: **Site settings → Environment variables**. В коде ключей нет.

| Переменная | Обязательна | Как получить |
|---|---|---|
| `TWELVE_DATA_API_KEY` | для золота/нефти | бесплатная регистрация на twelvedata.com (800 запросов/сутки) |
| `COINGECKO_API_KEY` | рекомендуется | бесплатный demo-ключ на coingecko.com (стабильный лимит вместо публичного 5–15/мин) |
| `TELEGRAM_BOT_TOKEN` | для бота | создать бота у @BotFather |

## Технологии

- Чистый HTML / CSS / JavaScript, без фреймворков
- TradingView Advanced Chart widget (встраиваемый iframe)
- Netlify Functions (Node.js) + Netlify Blobs для состояния
- Telegram Bot API через webhook (без long-polling и отдельного хостинга)
- Дизайн-система: тёмная палитра, шрифты Space Grotesk / IBM Plex, моноширинные цифры

## Запуск локально

```bash
npm install
npx netlify dev      # поднимает сайт + функции + Blobs локально
```

Открыть `index.html` напрямую тоже можно — тогда работают источники без ключа
(крипта, USD/RUB, новости), а блоки, зависящие от бэкенда (золото/нефть, вердикты,
топ-10), показывают демо-данные с пометкой DEMO.

## Деплой

1. Запушить в GitHub — Netlify задеплоит автоматически.
2. Задать переменные окружения (см. выше).
3. После первого деплоя: в Netlify Functions вручную запустить `crypto-list-refresh`
   и `indicators-refresh` один раз, чтобы не ждать первого срабатывания расписания
   (иначе топ-10 появится в течение суток, вердикты — в течение 6 часов).
4. Для Telegram-бота один раз настроить webhook (подставив свой токен и домен):
   ```
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<ваш-сайт>.netlify.app/.netlify/functions/telegram-webhook
   ```

## Структура

```
index.html                      — весь фронтенд (вёрстка, стили, логика)
avia-3d.html                    — 3D-визуализация (three.js)
netlify/functions/
  quotes.js                     — прокси котировок (Twelve Data)
  news.js                       — агрегатор новостей (RSS → JSON)
  crypto-list.js / -refresh.js  — топ-10 крипты (отдача / обновление)
  indicators-refresh.js         — расчёт индикаторов и вердиктов
  verdicts.js                   — отдача вердиктов
  alerts-check.js               — детект движений цены + рассылка в Telegram
  telegram-webhook.js           — обработчик команд бота
  lib/
    assets-registry.js          — реестр активов, фильтры, символы TradingView
    indicators.js               — RSI / EMA / поддержка-сопротивление
    coingecko.js                — клиент CoinGecko (топ-10, заголовки)
vendor/three/                   — локальная копия three.js
```

## Дисклеймер

Вердикты BUY/SELL и уровни уверенности — аналитическое мнение на основе технических
индикаторов, **не индивидуальная инвестиционная рекомендация**. Календарь событий и
таблица корреляций — демонстрационный макет. Перед торговыми решениями сверяйтесь с
первоисточником.
