# MERIDIAN — Multi-Asset Terminal — бриф проекта

## Что это
Сайт-агрегатор новостей и аналитики для трейдеров: крипта, форекс, товары (золото, нефть).
Аудитория — русскоязычные трейдеры/студенты, разбирающиеся в теме, но без опыта веб-разработки у автора проекта.

## Текущее состояние
Готов statiс-прототип: `index.html` (один файл, HTML/CSS/JS, без фреймворков, Chart.js с CDN для графиков).

Разделы на странице:
- Бегущая строка котировок (ticker tape)
- Market Pulse — индикатор общего настроения рынка
- Дашборд аналитики по 5 активам: BTC/USD, ETH/USD, XAU/USD (золото), WTI (нефть), USD/RUB
  - у каждого актива: вердикт (BUY/SELL/НЕ ВХОДИТЬ), факторы вердикта, разбивка уверенности (тренд/новости/объём), точность сигналов за 30 дней
- График цены (Chart.js) с переключением между активами
- Календарь экономических событий
- Таблица корреляций между активами
- Лента новостей с тегами по активам и силе влияния
- Личный watchlist (звёздочка, хранится в localStorage браузера)

Уже подключены живые данные (без сервера, прямой fetch из браузера):
- BTC, ETH — CoinGecko public API (`api.coingecko.com/api/v3/simple/price`, без ключа)
- USD/RUB — open.er-api.com (`open.er-api.com/v6/latest/USD`, без ключа)
- Золото (XAU) и нефть (WTI) — остаются демо-данными, для них нет бесплатного API без ключа

## Дизайн-система
- Палитра: тёмный фон (#0B0E13), панели (#131822/#172030), акцент — стальной синий (#5B9BD8), зелёный/красный для роста/падения (#3FCB82 / #E8555A)
- Шрифты: Space Grotesk (заголовки), IBM Plex Sans (текст), IBM Plex Mono (цифры/данные) — через Google Fonts
- Стилистика: терминал трейдера (плотная сетка данных, моноширинные цифры, бегущая строка), а не новостной блог

## Что нужно сделать дальше

### 1. Живые котировки золота и нефти
Нужен провайдер с бесплатным тарифом (обычно с API-ключом и лимитом запросов в день), например: Twelve Data, Metals-API, Alpha Vantage — нужно сравнить лимиты и выбрать. Важно: ключ нельзя хранить в клиентском коде (виден всем) — нужен небольшой backend-прокси (например, serverless-функция), который прячет ключ и отдаёт сайту готовые данные.

### 2. Реальная лента новостей
Официальные агентства (Reuters, Bloomberg) обычно не отдают RSS напрямую в браузер (CORS) и/или требуют платный доступ. Реалистичный план:
- Собрать список бесплатных источников с открытым RSS: ЦБ РФ, Investing.com, CoinDesk, EIA и т.д.
- Написать небольшой backend-сервис, который раз в N минут забирает эти RSS, приводит к единому формату (время/источник/заголовок/затронутые активы/сила влияния) и отдаёт JSON сайту
- Разместить сервис на бесплатном/дешёвом хостинге с поддержкой серверной части (например Render, Railway, Vercel Functions)

### 3. Вердикты BUY/SELL и уверенность
Сейчас это статичные демо-цифры. Дальше нужно решить: считать их автоматически по формуле (технические индикаторы + новостной фон) или проставлять вручную/полуавтоматически. Это отдельное обсуждение логики, не чисто техническая задача.

### 4. Хостинг
Статическая часть (сам сайт) — Netlify/Vercel, бесплатно, задеплоено через drag&drop.
Серверная часть (новости + золото/нефть) — отдельный процесс, нужен хостинг с поддержкой backend (см. пункт 2).
